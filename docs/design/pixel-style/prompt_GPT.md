设计一个个人博客中的互动房间页面。

这是一个像素 RPG 游戏里的私人基地，不是普通网页，也不是室内装修设计。

场景定位：
一个年轻程序员和机器人开发者的像素工作室。

参考风格：
Stardew Valley + Soul Knight + 经典16-bit RPG游戏地图。

不要人物角色。

房间本身作为主角。

视觉要求：

- 2D pixel art
- RPG game environment
- top-down 45 degree view
- pixel game map style
- 16-bit / 32-bit pixel graphics
- 黑色像素描边
- 清晰像素块
- 高饱和颜色
- 有空间层次
- 有物体阴影
- 有光照效果
- 有游戏地图感觉


场景布局：

整体是一个温暖的科技工作室。

中央区域：
保留空地，不放人物，用于视觉中心。

左侧区域：
大型木质书架。

书架上：
书籍、技术文档、笔记、卷轴。

代表：
博客文章、技术知识库。


右侧区域：
程序员电脑桌。

包含：
- 显示器
- 键盘
- 鼠标
- 代码界面
- 台灯

显示器发出蓝色像素光。

代表：
技术博客入口。


下方区域：
机器人实验台。

包含：
- 小型机器人小车
- 机械零件
- 传感器
- 电路板
- 工具箱

代表：
机器人项目展示。


墙面：
像素公告板。

上面有：
任务纸条
项目计划
开发日志

代表：
留言和动态。


角落：
像素宝箱。

代表：
Github项目仓库。


环境：

木质地板。
墙壁有科技装饰。
有植物。
有暖色灯光。
有桌椅。

整体像：
一个游戏玩家升级后的科技基地。


重要：

必须像游戏地图，而不是插画。

禁止：

- 普通房间装修
- 家居设计
- 真实室内
- 平面贴纸
- icon拼贴
- 卡通素材堆叠
- 白色背景
- 矢量插画
- 没有阴影
- 没有空间感

最终效果：

一个可以点击探索的像素 RPG 博客基地。


考虑网页实现需求：
所有物体需要独立分层，
家具、电脑、机器人、书架都应该像游戏素材一样可以单独点击交互。
保持清晰边界。
