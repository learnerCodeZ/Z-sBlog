设计一个像素 RPG 游戏中的工程机器人小车。

这是一个机器人开发者实验室里的核心设备，
不是普通移动小车，不是玩具。

参考：
Soul Knight + Stardew Valley + 16-bit pixel art game equipment。

机器人类型：
Educational Engineering Robot Platform

核心结构：

底部：
一个紧凑的四轮移动机器人底盘。

采用工业机械设计：
- 黑色和深灰色金属外壳
- 模块化装甲结构
- 四个机械轮
- 坚固底盘
- 工程机器人质感


顶部：
安装一个小型机械臂。

机械臂是视觉重点：

- 多关节机械臂
- 金属机械关节
- 旋转底座
- 小型夹爪末端执行器
- 可以抓取实验物品

机械臂呈待机姿态，
像实验室里的机器人助手。


顶部传感器：

- 小型激光雷达
- 摄像头模块
- 状态指示灯


细节：

- 电路接口
- 螺丝
- 金属连接件
- 蓝色科技灯
- 红色状态灯


整体感觉：

这是一个用于机器人实验、
自动导航、
人工智能研究的工程机器人。

像游戏中的高级科技装备。


像素风格：

- 16 bit pixel art
- 32 bit RPG sprite
- black pixel outline
- hard pixel edges
- high detail pixel object
- strong shadow
- 3/4 top view


适合作为个人博客像素房间里的可点击物品。


禁止：

toy car,
remote control car,
normal vehicle,
cute car,
cartoon vehicle,
simple robot,
flat sticker,
icon style,
realistic photo
