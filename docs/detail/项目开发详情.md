# 项目开发详情

> learnerCodeZ 个人博客的开发全记录。基于实际开发过程整理，供回顾 / 协作 / 维护参考。
> 更新于 2026-08-02。

## 一、项目概述

**learnerCodeZ 的个人博客**——一个静态优先的 Astro 站点，附带一个纯 Three.js 的 3D 互动房间。关注嵌入式 + AI 方向。

- **作者**：learnerCodeZ（GitHub: learnerCodeZ）
- **仓库**：github.com/learnerCodeZ/Z-sBlog
- **建立**：2026 年 7 月下旬
- **定位**：文章 / 随笔 / 项目 + 3D 房间彩蛋

## 二、技术栈

| 用途 | 选型 | 说明 |
|---|---|---|
| 站点框架 | **Astro v6** | 静态优先、默认零 JS、性能优先 |
| 3D | **Three.js**（纯命令式） | `/room` 子页面，不经 React |
| 留言 | **@waline/client** | 已嵌前端，后端待部署 |
| 样式 | **手写 CSS + CSS 变量** | 亮暗用变量切换，无 UI 框架 |
| 内容 | **Astro content collections** | `posts`（文章/随笔统一） |
| 部署 | GitHub Pages（规划） | site/base 走环境变量 |

> 历史包袱：曾尝试 React Three Fiber + @astrojs/react，因 Astro v6 的 rolldown-vite 兼容问题移除，改纯 Three.js。package.json 里残留的 react/r3f 依赖未清理（不影响构建）。

## 四、开发历程（关键阶段）

### 阶段 1 · 地基与文档
- 初始化 Astro（v6）+ Tailwind（后因 rolldown 兼容问题移除，改手写 CSS）
- 建立文档体系：README、AGENTS.md、develplan/（设计/结构/部署/路线/决策）
- 配置部署方案（site/base 走环境变量，Pages → 自有域名零改代码）
- 架构调研：探测参考博客（谢懿 Astro、周炯宇 VitePress、蔡明思 Next.js、Bryce Ikeda Hugo）

### 阶段 2 · 内容与首页
- content collection：文章/随笔合并为 `posts`，用 `type` 字段区分
- 首页：hero（learnerCodeZ + 嵌入式·AI）→ 最近（横滚，含项目）→ 博客（carousel）→ 项目（carousel）
- 导航：博客 / 项目 / 关于（留言入口移到房间）

### 阶段 3 · 3D 房间（核心，最大工程）
- 从 React Three Fiber → 纯 Three.js（规避 Astro v6 rolldown 兼容坑）
- 场景：L 型柜桌（中空框架 + 4 扇可开柜门）+ 笔记本 + 平板副屏 + 窗（窗帘盒 + 可拖动布帘，带褶皱）+ 地毯 + 椅子（五星脚 + 滚轮，可拖动 + 点击旋转）
- RoboMaster EP 小车（麦轮 + 机械臂 + 四面装甲 + 云台 + 激光雷达）
- 昼夜联动（博客亮暗 ↔ 房间白天/晚上）
- 交互：拖拽视角、拖窗帘、开关柜门（椅子挡门时打不开）、拖椅子、点椅子旋转、点留言板/小车
- 视觉：阴影 + 倒角（RoundedBoxGeometry）+ 补光
- 彩蛋入口：右下角浮动门 + logo 连点 3 次

### 阶段 4 · 留言 + 项目
- Waline 前端嵌入 `/guestbook`
- 房间留言板（hover 边亮 + tooltip + 点击跳 /guestbook）
- 项目数据化（projects.ts）+ `/projects` 列表 + 首页项目卡
- 状态色（active 琥珀 / maintained 青 / archived 暗灰）
- anchor scroll（点小车/项目卡 → /projects 对应项目滚到顶部）
- 第一个项目：EP 导航（EP_navigation_Ros1）

### 阶段 5 · 细节
- 亮暗模式（CSS 变量 + toggle，防闪烁）
- 页脚：建立时间 + 最近更新（git commit 日期自动）
- 部署 workflow（.github/workflows/deploy.yml，待 workflow 权限推送）
- 中英 toggle（占位，i18n 待做）

## 七、关键设计决策

- **纯 Three.js 不用 React**：Astro v6 + rolldown-vite 与 React 集成有兼容坑，改纯命令式 three.js，主站零 JS 不受影响
- **文章/随笔合并**：单一 posts collection + type 字段，父级导航"博客"
- **3D 与主站物理隔离**：three.js 只在 /room 加载，不进首页 bundle
- **项目入口彩蛋化**：去掉显式卡片，用浮动门 + logo 连点
- **留言板在房间内**：hover 边亮 + tooltip，点击跳 /guestbook
- **部署 site/base 走环境变量**：Pages → 自有域名零改代码
