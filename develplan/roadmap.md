# 搭建路线图（分阶段）

> 默认顺序，阶段间可按需调整。每个阶段都有明确"做完算完成"的标准——不追求完美，追求能跑、能看、能上线。
>
> 原则：**功能 / 内容先于形式**。视觉打磨放在功能跑通之后（阶段 4），3D 放最后（阶段 5）——因为它最重且独立，不能拖累主站上线。

## 阶段 0 · 地基
**目标**：空站能上线，部署 pipeline 通。
- 初始化 Astro + Tailwind。
- 配置 astro.config（site/base 走环境变量，见 [deployment.md](./deployment.md)）。
- 基础 Layout + 导航骨架 + 暗色模式。
- content collections 配置好（articles / essays schema）。
- GitHub Actions 部署 workflow + 仓库 Variables（SITE_URL / BASE_PATH）。
- **完成标准**：`用户名.github.io` 能打开一个空白但结构完整的站；push 到 main 自动部署成功。

## 阶段 1 · 内容骨架
**目标**：文章 / 随笔能写、能看。
- 文章列表页 + 详情页模板。
- 随笔列表页 + 详情页模板。
- frontmatter schema 落地（title / date / tags / summary / draft）。
- 代码高亮、阅读时长、tags 渲染。
- 各放一篇示例内容跑通。
- **完成标准**：从列表能点进详情，代码块 / 排版 / 阅读时长正常。

## 阶段 2 · 门面
**目标**：首页一眼说清"你是谁"。
- 首页：hero（定位 + 座右铭）+ 最新文章 / 随笔 + 精选项目。
- 关于我页（含感兴趣的方向）。
- 项目展柜（带 ACTIVE / MAINTAINED / ARCHIVED 状态徽章）。
- **完成标准**：陌生人打开首页，10 秒内知道你做什么；点进任何页不迷路。

## 阶段 3 · 交互与标配
**目标**：博客"该有的功能"齐了。
- 匿名留言（接 Waline）。
- RSS、sitemap、OG 图、基础 SEO。
- 站内搜索（Pagefind，纯静态）。
- 标签页（按 tag 聚合文章）。
- **完成标准**：能 RSS 订阅、能搜到文章、能匿名留言。

## 阶段 4 · 视觉打磨
**目标**：定调性，统一视觉语言。
- 拍板调性（极简 / 终端 / 动效派，见 [design.md](./design.md)）。
- 落配色 token、字体、间距系统。
- hero 动效 + 卡片交互（克制，framer motion）。
- 移动端适配检查。
- **完成标准**：全站视觉统一、动效不卡、移动端可用。

## 阶段 5 · 3D 子页面
**目标**：独立 3D 空间，不影响主站。
- 独立路由 `/room`，路由级懒加载（见 design.md "3D 隔离"）。
- 场景：男孩 + 电脑桌 + 摆件（具体设计另定，单独写 `develplan/3d-room.md`）。
- 进入时轻量加载指示，主站 bundle 不含 three.js。
- **完成标准**：`/room` 流畅可交互；首页性能不受其影响。

## 阶段 6 · 域名迁移
**目标**：上自有域名。
- 按 [deployment.md](./deployment.md) "迁移清单"操作：CNAME + DNS + 改 SITE_URL。
- **完成标准**：自有域名访问正常，旧地址自动跳转，HTTPS 生效。

---

## 阶段速查

| 阶段 | 一句话 | 能上线吗 |
|---|---|---|
| 0 地基 | 空站 + 部署通 | ✅ 第一版即可上线 |
| 1 内容 | 文章 / 随笔跑通 | ✅ |
| 2 门面 | 首页 / 关于 / 项目 | ✅ |
| 3 标配 | 留言 / 搜索 / RSS | ✅ |
| 4 视觉 | 定调性 + 打磨 | ✅ |
| 5 3D | 独立 3D 房间 | ✅ |
| 6 域名 | 自有域名 | ✅ |

> **每个阶段结束都是一个"可以上线的版本"。** 别等全部做完才部署——阶段 0 就该上线，然后持续迭代。
